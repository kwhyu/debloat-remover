# Terms of Use and Disclaimer

## What this software does

DebloatManager scans your device for preinstalled Windows apps, optional system features, and background services, and lets you end their running tasks or remove them. Some actions target core Windows components and require administrator privileges.

## No warranty

This software is provided "as is", without warranty of any kind, express or implied. Removing system components or Windows optional features can make Windows behave unexpectedly or break other applications. You are solely responsible for reviewing each item's risk level (shown in the app as Safe / Caution / Risky / Unknown) and for any consequences of removing it.

## Recommended precautions

- Use the built-in **Create Restore Point** option before performing risky actions, so changes can be undone through Windows System Restore if something goes wrong.
- Review the **Activity Log** panel and the log files under `%LocalAppData%\DebloatManager\logs` if you need to trace back what was changed and when.
