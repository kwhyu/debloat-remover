# Privacy Policy

DebloatManager does not collect, store, or transmit any personal data to any server.

- No analytics, no telemetry, no network requests are made by this application.
- All scanning and removal actions run entirely on your device, using local Windows APIs (registry, PowerShell, WMI/DISM).
- The only data DebloatManager writes is an activity log kept locally on your device, at `%LocalAppData%\DebloatManager\logs`. This log never leaves your device and is not accessible to anyone but you.
- Uninstalling DebloatManager does not remove existing log files; delete the log folder manually if you want them gone.

If this policy ever changes (for example, if a future version adds an optional update check), that change will be described here and reflected in a new release before it ships.
