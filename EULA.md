## 3. What the software does

With administrator rights, DebloatManager can:

- Remove Store apps for every user on the device, including their app data.
- Run the uninstallers of installed programs and, if you choose, delete their remaining folders.
- Turn off Windows optional features.
- Stop and disable Windows services.
- Create System Restore points, which also turns on System Protection for the system drive if it is off.

Many of these changes cannot be fully undone.
